HYPERLIQUID RADAR — ОПИСАНИЕ ДЛЯ РАЗРАБОТЧИКА

Папка проекта:
C:\Users\1\Desktop\Hyperliquid Radar

Локальный сайт:
http://127.0.0.1:8765

Основные файлы:
- index.html — интерфейс и клиентская логика радара.
- server.ps1 — HTTP-сервер Windows и API для автоторговли.
- autotrade.ps1 — Bybit Mainnet, защищённое хранение ключей, расчёт и отправка ордеров.
- push-server.js — Push-уведомления и отслеживание адресов в фоне.
- sw.js — service worker для push.
- launch.ps1 — запуск на Windows.
- deploy-ubuntu.sh, UBUNTU-DEPLOY.md — развертывание на Ubuntu 24.04.

ИСТОЧНИКИ ДАННЫХ
- Hyperliquid WebSocket: live trades и userFills.
- Hyperliquid Info API: позиции, clearinghouse state, история.
- Bybit Mainnet API: инструменты, баланс, плечо, рыночные ордера.

КЛЮЧИ И БЕЗОПАСНОСТЬ
- Bybit API Key и Secret вводятся в блоке автоторговли.
- Ключи не сохраняются в браузере.
- Сервер хранит ключи в защищённом хранилище Windows DPAPI.
- Автоторговля использует Bybit Mainnet, не тестнет.

ОСНОВНЫЕ КНОПКИ И НАСТРОЙКИ
- Запустить анализ / Остановить анализ: открывает или закрывает WebSocket-анализ.
- Активы для discovery: монеты, по которым ведётся поиск.
- Добавить пару Bybit: принимает BTC, BTC/USDT или BTCUSDT; добавляет только существующую на Bybit пару.
- Крестик у пары: удаляет пользовательскую пару.
- Порог крупной сделки: USD-сумма, после которой событие отмечается как whale.
- Авто-watch адреса от USD: адрес автоматически сохраняется при прохождении порога суммарного объёма.
- Проверять пакетами: размер пакета проверки новых адресов.
- Окно дробления: период объединения дробных исполнений.
- Сохранённые адреса: ручной список адресов watchlist.
- Крестик рядом с адресом: удаление с подтверждением.
- Анализировать сохранённые адреса:
  включено — анализируются сохранённые адреса через userFills;
  выключено — discovery ищет только несохранённые адреса.
- Включить push: включает браузерные системные push-уведомления.
- CSV: экспорт событий.
- Excel: экспорт событий и PnL.
- PnL: экспорт таблицы PnL.
- Очистить: очистка локальной истории радара.
- Обновить 3 месяца: загрузка истории и расчёт PnL за 90 дней.
- Клик по адресу / Открыть портфель: открывает подробный портфель.
- Сохранить: добавляет адрес в watchlist; сохранённый адрес отмечается «Сохранён».
- Сохранить настройки автоторговли: сохраняет API-ключи, адреса, процент депозита и плечо.
- Включить автоторговлю: включает реальные ордера Bybit Mainnet.

ПРАВИЛА ОТОБРАЖЕНИЯ
- Показывать только точные LONG и SHORT.
- Показывать только ОТКРЫТИЕ и ЗАКРЫТИЕ.
- Дроблённые исполнения объединяются по адресу, активу, позиции, действию и окну времени.
- Столбец «Время покупки»: одна сделка — одно время; дробление — интервал начала и конца, например 15:55–16:45.
- «Отклонение от рынка»: процент и сумма изменения в USD; сортировка от наибольшего плюса к меньшему.
- Верхняя полоса лидеров: максимальный объём, лучший открытый PnL, лучший закрытый PnL; адрес можно открыть и сохранить.
- В портфелях показываются два лидера по объёму, открытому PnL и закрытому PnL.
- Открытый PnL: только активные прибыльные позиции с торговлей сегодня или вчера.
- Закрытый PnL: период 3 месяца; адрес показывается только если у него нет минусовых закрытий за период.
- В подробном портфеле: вход, рыночная цена, изменение, PnL, время открытия, время закрытия и лучшая позиция.

ЧТО ВСЕГДА СКРЫВАТЬ
- Любые активы с префиксом xyz:.
- Значения N/A, Н/Д и прочерки как данные.
- Строки без определённых LONG/SHORT и ОТКРЫТИЕ/ЗАКРЫТИЕ.
- Убыточные позиции в блоке открытого PnL.
- Адреса с хотя бы одним минусовым закрытием в блоке закрытого PnL.
- Внутристраничные нижние всплывающие уведомления.
